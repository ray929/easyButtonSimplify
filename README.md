# Easy Button Simplify

> A cleaner look for Blizzard's native action bars: no borders, bigger icons, tidy text and no extra-button clutter.
>
> 让暴雪原生动作条更简洁：去掉边框、图标放大、文字整齐、清理额外按钮装饰。

## Features / 功能

- Hide the native action bar borders and enlarge icons, with a thin 1px black outline.
- 隐藏原生动作条边框并放大图标，带 1 像素黑色描边。
- Adjust the keybind / stack count / macro text size with a thicker outline.
- 调整按键 / 层数 / 宏文字的字号并加厚描边。
- Strip the decorations and borders from the extra action button (zone abilities).
- 清理额外技能按钮（区域技能）的装饰材质与边框。
